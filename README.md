# wedding-invitation
SURUMI & MOHAMMED MUSSAMMIL — WEDDING INVITATION WEBSITE

Preview:
- Keep index.html and the assets folder together.
- Open index.html in a browser to test the envelope animation.
- Tap/click the closed envelope to reveal the open envelope and the wedding card.

Free hosting (to get a shareable website link):
1. On your phone or computer, sign in to GitHub and create a new public repository named wedding-invitation.
2. Upload index.html and the complete assets folder (with all three images).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. The free link will look like https://YOUR-USERNAME.github.io/wedding-invitation/ . Replace YOUR-USERNAME with your GitHub username.

The link above is an example format, not a live published website. The site has not been uploaded to a hosting account.
